# WayPoint ✈️

WayPoint es una aplicación iOS moderna desarrollada en **SwiftUI** con arquitectura **MVVM**, diseñada para la gestión integral de viajes, seguimiento de vuelos en tiempo real y visualización geográfica.

## 🚀 Características
- **Gestión de Itinerarios**: Persistencia local nativa utilizando **SwiftData**.
- **Seguimiento de Vuelos**: Consultas asíncronas de estado de vuelos con **`async/await`** y cliente HTTP genérico sobre `URLSession`.
- **Mapas Interactivos**: Integración con **MapKit** para visualizar itinerarios y puntos de interés.
- **Navegación Centralizada**: Flujo de pantallas administrado con `NavigationStack` y un `NavigationRouter` global.

## 🛠️ Tecnologías
- **iOS 17.0+** | **Swift 5.9+**
- **SwiftUI** & **Combine**
- **SwiftData**
- **MapKit**
